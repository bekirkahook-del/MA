# M&A Prep (mnaprep.com): quick context for new sessions

Owner: Bekir Kahook (Ohio State finance student). Wants things done for him, short casual answers, tables and numbers.

## Repo and deploys
- GitHub `bekirkahook-del/MA`, branch `main`. Netlify auto-deploys on push.
- **Every production deploy costs 15 Netlify credits (plan: 1,000/month).** Bundle changes and push as few times as possible.
- `netlify.toml` `ignore` skips deploys when a push only touches `data/wire.json`, `social/`, `guides/_src/`, `supabase/` or `*.md`.
- Always `git pull --rebase` before `git push`. The push prints a "repository moved" notice; it's harmless.
- Static site: `index.html` + `js/app.js` (big classic script; globals `S`, `isPro()`, `questEvt()`), `js/rewards.js` (Pro page, billing sync), `js/grow.js` (sign-up nudges + funnel events), `js/admin.js` (owner stats page, `#stats`).
- Guides are generated by `guides/_src/*.py` (`extra.py`, `seo.py`, `og.js`).

## Backend
- Supabase table `docs` (col, id, uid, data). Users can't write `billing` or `ai_usage`; `views/_pro` is the server-written list of Pro members.
- Netlify functions in `netlify/functions/`. Shared helpers in `_lib/common.mjs`: `tierOf()`, `AI_LIMITS`, `rebuildProList()`, `isOwner()`.
- Pay tiers are decided on the server from the billing doc: free (8 AI uses/day), trial (3 days, once per account, 20/day), season (40/day), pro (100/day). Earned rank-up Pro days = trial level. `grant.mjs` = owner gives Pro.
- Stripe is live: webhook `stripe-webhook.mjs` listens to checkout.session.completed + customer.subscription.created/updated/deleted. Secrets live only in Netlify env vars; never ask for, paste or print them.
