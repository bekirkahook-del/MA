How to learn Excel for investment banking

Updated Nov 17, 2026 · M&A Prep

Excel is the main tool in investment banking, and being fast in it is a real advantage. The good news is that you can learn the important parts without taking a whole course.

Here is what to focus on and how to practice.

Short answer

Focus on keyboard shortcuts, core formulas such as IF, SUMIFS, INDEX/MATCH or XLOOKUP, IRR and NPV, and clean modeling habits such as color-coding inputs and formulas. Practice by building a simple three-statement model and DCF from scratch, because speed and accuracy come from repetition.

1. Learn the keyboard

Bankers work mostly without a mouse. A few shortcuts worth learning first:

ShortcutWhat it does
F2Edit the selected cell
F4Cycle through absolute and relative cell references
Ctrl + arrow keysJump to the edge of your data
Ctrl + Shift + arrow keysSelect a whole block of data
Alt + =Quickly add up a column or row
Ctrl + [Jump to the cells a formula depends on

2. Learn the core formulas

Start here

  • IF and nested logic
  • SUM, SUMIFS and AVERAGE
  • INDEX/MATCH or XLOOKUP for looking up data
  • NPV and IRR for returns
  • MIN, MAX and ROUND for clean outputs

3. Follow modeling conventions

Good habits

  • Color-code: blue for hard-coded inputs and black for formulas is a common convention
  • Keep inputs in one place and never hide numbers inside formulas
  • Check that the balance sheet balances and cash ties
  • Keep formats consistent so other people can follow your work

4. Build things from scratch

The best practice is to build a model yourself. Start with a simple three-statement model, then add a DCF, then try a paper LBO. See how to walk through a DCF and what is an LBO to know what each should include.

A simple practice plan

WeekGoal
1Learn the shortcuts and practice navigating without a mouse
2Learn the core formulas and use them on a small data set
3Build a simple income statement and balance sheet forecast
4Add a DCF and review your own work for errors

Common questions

Do I need to know Excel before an internship?
Not perfectly, but the more comfortable you are, the faster you learn on the job.
Do I need to learn VBA or macros?
Not usually for analyst roles. Strong core Excel skills matter more.
Are online modeling courses worth it?
They can help if you finish them and build your own models afterward, but practice is what makes the skills stick.
